Stylish components to integrate — ranked top picks (multi-agent research)

Researched by 4 parallel agents across Aceternity, Cult UI, BEUI, Shadcn Space, CodeFronts, RareUI, Watermelon, Skiper, + award-site animation patterns. Ranked by style-impact for the emerald security theme.

#1 · ENCRYPTED / SCRAMBLE TEXTAceternity — Encrypted Textmotion · single-file · 10/10Gibberish→plaintext reveal that reads as literal decryption. THE security-persona signature. Use on hero sublines / section headers.
#2 · SCROLL-LINKED LINE-MASK REVEALAward-site patternsmall JS / CSS · 9/10Headings/paragraphs reveal word-by-word via clip-path mask as they enter viewport — the #1 "not AI-made" reveal used by Awwwards winners.
#3 · TEXT FLIPPING BOARD (SPLIT-FLAP)Aceternity — Text Flipping Boardmotion · 9.5/10Vestaboard-style split-flap characters with mechanical flip. Perfect rotating skills/status ticker under the hero.
#4 · GLOWING EFFECT (CURSOR-ADAPTIVE BORDER)Aceternity — Glowing Effectmotion · 9/10Cursor-following emerald glow border on cards — premium upgrade over the static shine border.
#5 · ASCII ART (BINARY/MATRIX)Aceternity — ASCII Artcanvas, no motion · 9.5/10Image → live ASCII with binary/braille/matrix charsets. Pure terminal aesthetic for the about/photo cell.
#6 · EVERVAULT CARDAceternity — Evervault Cardmotion · 9/10Hover card revealing encrypted text — literally inspired by a security company's branding. Project-card variant.
#7 · GRID BEAM BACKGROUNDCult UI — Grid Beamcanvas, no motion · 9/10Soft glowing beams traveling grid dividers — emerald "ocean" palette. Next-level hero background.
#8 · LIGHTBOARD (DOT-MATRIX)Cult UI — LightBoardReact + timers · 9/10Dot-matrix marquee that renders moving text + click-drag drawing. Hardware-terminal skills ticker — beats the CSS marquee.
#9 · COMMAND PALETTE (CMD-K)Shadcn Space / Skiper — Commandcmdk + motion · 8.5/10Ctrl/Cmd+K palette as site navigation — terminal-native, the definitive pro-portfolio interaction.
#10 · SHADER BACKGROUND (DITHER/GOD-RAYS)BEUI — Shader Background@paper-design/shaders-react · 9.5/1022 canvas shaders (dithering, perlin, god-rays, dot grid) — dither variant is default #00ff9d, pure cyberpunk terminal.
#11 · TRACING BEAMAceternity — Tracing Beammotion · 8.5/10Emerald beam traces an SVG path as you scroll — run it along the timeline or as a vertical process line.
#12 · GRID REVEAL (PROJECTS)RareUI — Grid Revealmotion · 9.5/10Image loading that subdivides into cells then resolves — procedural "generating" pill is pure terminal/security. Project screenshots.
#13 · STAGGERED GRID REVEALSPattern (CodeFronts CSS scroll)CSS + IO · 8/10Cards rise in staggered by index (~80ms) when the grid enters — subtle, premium, no bounce.
#14 · GLITCH/SLICE ON PROJECT MEDIAPattern (cyber portfolios)small JS · 8/10Project screenshots break into clip-path slices with a faint emerald split on hover — "compromising the image". On-brand, use occasionally.

#16 · FLUID ORBRareUI — Fluid OrbWebGL canvas · 9/10Emerald fluid orb behind hero/contact — ambient, honors reduced-motion. One WebGL accent max.
#17 · LAMP EFFECT (SECTION OPENER)Aceternity — Lamp Effectmotion · 8.5/10Light beams converge into an illuminated section heading — cinematic section openers, tint emerald.
#18 · STICKY PIN + HORIZONTAL RAILPattern (GSAP ScrollTrigger)GSAP · 9/10 flashOne section pins while project cards travel horizontally. The flashiest item — use once max, or skip for restraint.
#19 · DOTTED GLOW BACKGROUNDAceternity — Dotted Glow BGmotion · 8.5/10Pulsing dot-grid with per-dot glow — layers over aurora without competing.

The "senior engineer spec-sheet". Scroll-tested clean. Maps to zinc-950 + emerald. BEST FIT.
#2 · TIMELINE-AS-AUDIT-LOG (VERIFIED)Diogo Correia modelbrowser-verified · light · timeline-ledParticle hero + dated evidence timeline (CTFs, CVEs, tools) + GPG key in socials. Reads like an audit log — native security credibility. Graft the timeline + GPG/bounty/CVE references onto the dark theme.
#3 · SIDEBAR WORKSPACE (ACETERNITY)Sidefolio templateNext.js + motion · darkPersistent left identity/nav sidebar, content scrolls beside, collapsible on mobile. IDE/security-tool workspace feel.
#4 · CENTERED-MINIMAL EDITORIALMinimal Portfolio templateNext.js + motion · dark-firstOne centered hero statement over whitespace, content stacked down the middle. Calm, confident, safest "senior engineer" read.
#5 · ATMOSPHERIC DARK HEROAceternity Hero blocks (beams/grid/noise)dark-first effectsGrid/beam/scanline background behind a centered headline + terminal card as hero visual. Technical "lab" mood, minimal motion.
#6 · EDITORIAL GIANT TYPE + NUMBERED INDEXJean Rottner / Casa di Solare modellight · editorialOversized mono headline (e.g. "$ whoami — security engineer") + numbered index of advisories/projects. Cheapest route to premium; keep to one declarative line.
#7 · PROOF WALL + CASE STUDIESPixelmatters modellight · agencyStatement hero → logo wall (HackerOne, Bugcrowd, MSRC) → 2-3 deep case studies. Fastest credibility; risks agency feel.
#8 · NUMBERED SECTIONS + SCROLL-SPY RAILPattern (award editorial sites)CSS + ~15 lines JSEvery section gets "01. experience" mono headers + thin right rail showing current number. Reads as documentation — a security engineer's native genre. Combine with #1.
#9 · BRUTALIST LIST (MONO-ONLY)Minimal Gallery personal sitesCSS-onlyWhole page as one mono list, hairlines, emerald only for links/status. Max credibility, sheds warmth; pair with the terminal hero.
#10 · TERMINAL-AS-HERO (BOOT SEQUENCE)Pattern (dev/security sites)small JSHero IS the terminal: $ whoami, typed one-liner, modules-as-sections scan. Strongest persona signal; only lands if dead-restrained (no glitch/matrix-rain clichés).

// verdict — build this combination

  • Shell: #1 dark two-column sidebar (Brittany Chiang) — left identity/nav rail + right content, zinc-950 + emerald.
  • Experience: #2 audit-log timeline (Diogo) — dated evidence rows with CVEs/CTFs + tech tags, on dark.
  • Hero: keep the terminal card; add "$ whoami" editorial scale + GPG/bounty links in socials.
  • Sections: #8 numbered mono headers + scroll-spy rail (reads as documentation).
  • Drop: bento-as-"look at me" → replace with evidence timeline; no social-proof/testimonial walls.
